# 审读与证据核查流程

本文件是执行顺序与台账要求。每阶段只陈述实际完成的动作；下载、读文、读图、计算和复现不可互相代替。

## 1. 对象、版本和材料覆盖

- 记录题名、DOI、发表时间，识别预印本、正式版、修订、更正、作者回复之间的关系。同一研究的不同版本不得重复作为独立证据。
- 在授权范围内查找正文、补充材料、Source Data、代码、数据仓库、公开评审与更新记录，记录访问日期。
- 材料逐项记录：发现链接、取得文件、读取文本、查看图像、完成计算。取得本地文件才计算大小与 SHA-256；失败记录真实原因。
- 输出研究对象表、材料清单、审查范围、选定检查清单、排除项和缺失材料。非公开资料不上传第三方。

## 2. 先建立主张—证据链

阅读摘要、引言、结果、方法、图注和相关补充材料，回答科学问题、相对贡献、方法逻辑、关键证据、优势和作者承认的限制。

将核心主张编号并记录：主张 → 实验/数据 → 图表 → 方法 → 统计/计算 → 适用边界。分开标注描述、预测、因果、机制和应用外推。创新性优先依据发表当时的原始论文；后续比较另列。

## 3. 生成可检验的候选问题

候选问题必须有本篇论文的触发位置。检查摘要、正文、图、表、图注、方法和补充材料中的样本量、分母、比例、单位、时间点、组别、定义和结论强度。

涉及图表时实际看图，检查坐标/对数尺度、误差条、颜色、样本点、图例和归一化。原文优先于 OCR；数字化读数标不确定性，不冒充原始观测。图片相似只登记线索。

Methods 参数不能只抽查核心实验。建立“参数—单位—对象—条件—位置”台账，至少覆盖切片厚度、温度、时间、转速/离心力、浓度、体积、剂量、尺寸、分辨率和阈值。先用脚本提取所有带单位数值，再逐项检查：

- 同一技术类型和上下文是否兼容，例如包埋方式、切片设备、染色与成像方式；
- 是否存在 10 倍/1000 倍数量级、单位误写或小数点移位；
- 正文、图注、补充方法和试剂说明是否给出不同值；
- 外部常见范围是否仅作为筛查线索，最终是否回到本篇原文和实际实验记录。

直接确认“发表值异常”不等于直接确认“正确值”。没有实验记录或作者确认时，将推测修正值写入替代解释/建议，不把它冒充已核验事实。若任务未做全量参数筛查，必须在限制中明确说明。

根据研究问题检查实验单位、重复层级、对照、随机化、盲法、纳排、缺失、混杂和外推。统计检查包括配对、单双侧、方差、多重比较、效应量、置信区间、模型和处理顺序。尚未验证者不得标 `confirmed`。

## 4. 深入核查与最小复算

按核心主张影响、现有证据和可验证程度排序。数值矛盾先检查子集、分母、权重、时间点、缺失规则和舍入。图表矛盾追踪样本身份 → 源表标签 → 数值 → 变换 → 绘图标签，不凭生物学预期指定真标签。

统计先按作者声明复算，再做有理由且预先说明的替代分析；分别回答计算是否一致和模型是否适合设计。记录输入位置、n、选项、软件、脚本、输出、发表精度和容差。代码模型重点追踪数据划分、预处理、特征选择、调参、训练与测试边界；没有训练代码时只报告风险。

## 5. 反证与敏感性

每条拟保留问题检查最强替代解释：正文/补充是否已说明、命名是否只是表面差异、实验是否不同、评审是否已补证据、版本是否更新、是否误读坐标或归一化。

无法确认实际影响时，可给条件敏感性或界限，但明确前提与 upper/lower。没有真实配对不得构造对应关系；上界跨过阈值不代表实际结果一定不显著。不显著不得写成等效或无效应。

## 6. 影响判断

逐项回答问题层次、纠正后改变什么、关联哪个核心主张、独立支持证据是否仍在、最少新增材料是什么。分别记录：

- 状态：confirmed / conditional / needs_clarification / ruled_out / resolved。
- 证据强度：high / medium / low / undetermined，并写理由。
- 影响：reporting / local_result / key_claim / unknown，并写理由。

不推断造假概率或个人责任。没有发现问题时列通过项与盲区，不认证全篇真实性。

## 7. 报告与多篇比较

报告固定包含范围与版本、技术概述、主张—证据、通过检查、主要/次要问题、已排除/解决、敏感性、未完成项和综合评价。重大问题按对主张影响组织。

多篇时比较问题、数据来源、样本独立性、评价条件、证据强度、分歧与后续研究；检查共享队列、重复数据和版本关系，不强排不可比指标。建议区分支撑当前结论所必需与超出范围的后续工作。
