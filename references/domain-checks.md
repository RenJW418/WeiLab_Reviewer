# 按论文类型加载的检查模块

通用流程始终保留，只加载与研究设计相关的模块。

## 生物医学与实验研究

- 识别真正的实验单位，区分生物学重复、技术重复、同一患者/动物的配对、纵向或嵌套测量。
- 检查对照、批次、随机化、盲法、纳排、缺失数据和归一化；先确认作者是否已报告。
- 全量筛查 Methods 的数值参数和单位，并将参数与具体对象、处理阶段和仪器绑定。重点排查小数点移位、单位混用，以及与包埋、切片、染色、培养、给药、离心、成像或测序技术不兼容的数量级。
- 对组织学方法区分冰冻、石蜡、树脂和超薄切片；厚度必须与切片设备、染色方式和显微成像方式共同判断，不能只凭一个“常用值”确认错误。
- 区分观察关联、预测、因果、机制和临床/应用外推所需证据。
- 聚类或层级分析只使用真实身份映射；缺失时报告阻塞或条件性界限。

## 机器学习与计算生物学

- 追踪训练/验证/测试边界，以及预处理、特征选择、超参数搜索是否只在训练信息内完成。
- 查患者/样本重复、同源序列/家族泄漏、时间泄漏、伪标签来源与共同上游模型。
- 检查基线公平性、调参预算、随机种子、消融、外部验证和评价条件可比性。
- 多模型一致不自动构成独立验证；未取得代码时将泄漏写为风险而非已发生事实。

## RNA、蛋白与结构预测

- 区分计算结构/实验结构、二级/三级结构、模型置信度/实际误差、代表结构/完整集合。
- 检查是否利用测试真值挑候选或拼接最优结果，是否披露 oracle 辅助；理论上限不得包装为可部署性能。
- 多模型或 teacher 场景记录共同训练数据、上游模型、伪标签与依赖关系。
